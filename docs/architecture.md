# 출처 시스템 구조

이 리포의 모듈이 원래 어디에서, 어떤 역할을 했는지 설명합니다. 두 시스템 모두 1인 개발이며 전체 소스는 비공개입니다.

## BeanPal — 커피 로스터 제어·기록 데스크톱 앱

```
 ┌──────────────── 데스크톱 (Windows / macOS) ────────────────┐
 │  React + TypeScript (Tauri)  ── 실시간 그래프, 프로파일 재생  │
 │            │ WebSocket / REST                               │
 │  FastAPI 백엔드 ── 계산 단일화(온도 변화율·예측·이벤트 감지)   │
 │            │                                                │
 │  통신 계층 ── 장비 프리셋(JSON) → 프로토콜 드라이버            │
 │     Modbus RTU/TCP · Siemens S7 · 시리얼 텍스트 · BLE ·       │
 │     WebSocket · USB HID … (16종)                             │
 └───────────────┬────────────────────────────────────────────┘
                 │ RS-485 / USB-시리얼 / TCP / BLE
       로스터 제어기·온도 지시계·가스 밸브·인버터 (89개 브랜드 213개 프리셋)
```

- 장비마다 코드를 쓰지 않고 **프리셋(JSON) 하나로 장비를 정의**합니다. 새 로스터 지원은 대부분 프리셋 추가로 끝납니다.
- 통신부 재설계 때 **장비 없이 검증하는 하니스**를 먼저 만들었습니다: 열 모델 → 슬레이브 시뮬레이터 → 결함 주입 → 전송 추상화 → 리더.
  이 리포의 `roaster_model.py`, `modbus_rtu.py`, `faults.py`, `transport.py`, `reader.py`가 그 하니스에서 나왔습니다.
- 가스 밸브 제어는 밸브 개도가 아니라 **가스 압력을 목표로 하는 폐루프**로 바꿨습니다. 같은 개도라도 공급 압력에 따라 화력이 달라지기 때문입니다.

## AgroKeep — 농산물 저장 실험 챔버 데이터 수집 시스템

정부 R&D 과제의 실험 환경 구축 부분으로, 실험 챔버의 환경·가스·무게·이미지를 무인으로 연속 수집합니다.

```
 챔버 (여러 동)                          엣지 (Raspberry Pi, 챔버당 1대)              서버 (워크스테이션)
 ───────────────                         ─────────────────────────────              ─────────────────────
 I2C: CO₂·온습도·VOC·분광 센서  ──────▶  Python 에이전트 (systemd, 워치독)  ──WS──▶  FastAPI 수집기
 RS-485: 가스 센서 3종, 저울    ──────▶   · 버스별 상호배제·재시도                   TimescaleDB
 CSI: 카메라 + 조명             ──────▶   · 값 검증(없는 값은 버림)                  대시보드·원격 명령
 PWM·SSR: 펌프, 조명            ◀──────   · SQLite 저장 후 전송 버퍼                 데이터 → 학습용 파일
                                          · 서버에서 코드 당겨받기(회선 불량 대응)
```

- 엣지는 **모든 측정을 로컬에 먼저 저장**하고 전송합니다(`outbox.py`). 회선이 끊겨도 데이터는 남습니다.
- 한 RS-485 버스를 가스 센서 3개와 저울이 나눠 씁니다. 버스 단위 잠금으로 요청-응답을 한 번에 하나씩만 보냅니다.
- 이 리포의 `lenframe.py`, `sensirion.py`, `outbox.py`, 시리얼 재오픈 로직이 여기서 나왔습니다.
  가스 센서 제조사의 명령 체계와 현장 설정은 포함하지 않았습니다.

## 이 리포에서 C++로 옮긴 범위

| 모듈 | Python | C++ | 대조 검증 |
|---|---|---|---|
| CRC-16/MODBUS, CRC-8/Sensirion | ✓ | ✓ | 임의 바이트 3,000건 |
| Modbus RTU 0x03/0x06 코덱, 슬레이브 | ✓ | ✓ | 변형된 응답 3,000건, 요청 3,000건 |
| 길이 접두형 프레임 + 스트림 디코더 | ✓ | ✓ | 잡음 섞인 스트림, 임의 분할 3,000건 |
| SCD41/SHT45 변환 | ✓ | ✓ | 전체 입력 범위 3,000건 |
| 시리얼 전송 + 리더 | ✓ | ✓ | 같은 결함 시나리오 5종, 가상 장비 통합 |
| SCD41 상태 관리, 저장 후 전송 버퍼 | ✓ | — | Python 단위 테스트 |
